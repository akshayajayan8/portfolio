# Akshay Ajayan — Static Portfolio

## Files
- `index.html` — single-page portfolio
- `style.css` — all responsive styling
- `assets/dummy-person.svg` — temporary transparent-background portrait placeholder

## Before hosting
Open `index.html` and replace:
1. `assets/dummy-person.svg` with your real backgroundless portrait (PNG/WebP recommended).
2. `your-email@example.com` with your email.
3. `919000000000` in the WhatsApp link with your number including country code.
4. `https://www.linkedin.com/in/your-profile/` with your LinkedIn URL.

No build step is required. Upload the files to any static hosting service.
